# P11 — Internationalization (English / Mandarin / Indonesian)

**Track:** Cross-cutting (Team F) · **Depends on:** P0 · **Parallel with:** everything · **Size:** S–M

## Goal
A working i18next setup with `en`, `zh` (Mandarin), `id` (Indonesian) locales, a language switcher, and a
keyed string discipline that the screens (P8) and result/fan names (P3) plug into. Reuse Junto's init pattern.

## Deliverables
```
packages/i18n/index.ts            # i18next init + setLocale() + typed t() helper
packages/i18n/locales/en.json
packages/i18n/locales/zh.json
packages/i18n/locales/id.json
packages/i18n/keys.ts             # (optional) typed key union for compile-time safety
packages/i18n/README.md           # how to add a key; namespacing; pluralization
```

## Detailed spec
- **Init:** i18next + react-i18next; resources for `en|zh|id`; fallback `en`; detect from profile/`settings.locale`;
  persist choice to profile (P10) and local storage. Mirror `junto-mobile/lib/i18n.ts` structure (copy + add `zh`).
- **Namespaces:** `common, lobby, table, match, result, shop, daily, settings, errors, fan`. Keep flat-ish, readable keys.
- **`fan` namespace** maps every `ScoredPattern.nameKey` from the fan-table (P3) to localized names (All Pungs, Half Flush,
  Pure One Suit, Thirteen Orphans, dragons/winds, …) in all three languages.
- **Switcher:** exposed via Settings (P8); switching re-renders live.
- **Copy guardrails:** translations must avoid gambling terms in every language (no 赌/casino/jackpot/taruhan-judi);
  use neutral "coins/table/lucky draw" equivalents. Have a native/fluent reviewer pass `zh` and `id` before launch.
- **Glyphs:** ensure the font stack (P9 tokens: Noto Sans/Serif SC) covers Mandarin; verify no tofu boxes.

## Contracts
- **Consumes:** `Profile.locale` (CONTRACTS §4), `nameKey`s from the fan-table (P3).
- **Exposes:** `t()`, `setLocale()`, `useTranslation` — consumed by P8 screens and P9 components.

## Acceptance criteria
- [ ] App boots in `en`, `zh`, `id`; switching locale updates all visible strings with no raw keys.
- [ ] Every `fan` nameKey resolves in all three languages (test iterates the fan-table).
- [ ] Locale persists across reload and to the profile.
- [ ] No untranslated key lint check passes for P8 screens (grep for raw literals + missing keys).
- [ ] Mandarin + Indonesian render without missing glyphs.
